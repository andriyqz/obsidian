Рекурентні нейронні мережі (RNN) — це клас мереж, здатних прогнозувати майбутнє, аналізуючи часові ряди (наприклад, кількість активних користувачів, температуру або траєкторії автомобілів). Окрім RNN, для обробки послідовностей можна використовувати звичайні повнозв'язні мережі (для коротких послідовностей) або згорткові мережі (для дуже довгих, як-от аудіо).

**1. Рекурентні нейрони та шари**
На відміну від мереж прямого поширення, RNN мають зв’язки, що вказують назад.
- **Рекурентний нейрон:** на кожному часовому кроці t (фреймі) він отримує вхідні дані $x_t$​ та свій власний вихід з попереднього кроку $y_{(t-1)}$
- **Розгортання в часі:** представлення нейрона у вигляді ланцюжка, де для кожного кроку відображено його стан.
- **Ваги:** кожен нейрон має два набори ваг — $W_x$​$ для поточних входів та $W_y$​​ для виходів попереднього кроку.

**Математичне обчислення виходу (для міні-батчу):** $Y_{(t)}​=\phi(X_{(t)}​W_x​+Y_{(t−1)​}W_y​​+b)$

**2. Комірки пам'яті та типи послідовностей**
Частина мережі, що зберігає стан між кроками, називається **коміркою пам'яті**.
- **Sequence-to-sequence (послідовність-у-послідовність):** на вхід подається послідовність, на виході — теж (наприклад, температура за кожну з останніх 24 годин $\rightarrow$ Вихід — прогноз температури на кожну з наступних 24 годин.).
- **Sequence-to-vector (послідовність-у-вектор):** ігноруються всі виходи, крім останнього (наприклад, відгук на фільм із 100 слів $\rightarrow$ Вихід — оцінка від 1 до 5 зірок або вектор класифікації («позитивний/негативний»).
- **Vector-to-sequence (вектор-у-послідовність):** один вхід подається повторно на кожному кроці (наприклад, зображення з CNN $\rightarrow$ Вихід — текстовий опис: «Собака біжить по траві).
- **Encoder-Decoder:** послідовність-у-вектор (енкодер), за якою йде вектор-у-послідовність (декодер). Використовується для машинного перекладу

**3. Навчання RNN (BPTT)**
Для навчання використовується алгоритм **зворотного поширення помилки крізь час (Backpropagation Through Time, BPTT)**. Мережа розгортається, обчислюється функція втрат, а градієнти проходять назад крізь усі кроки часу.

**4. Прогнозування часових рядів (Проєкт)**
У главі розглядається задача прогнозування пасажиропотоку в Чикаго.
- **Базова лінія (Naive forecasting):** припущення, що значення буде таким самим, як 7 днів тому.
- **Підготовка даних:** створення вікон (windows) фіксованої довжини, де цільове значення — це наступний крок часу.

**Приклад коду: Реалізація RNN «вручну» (без готових комірок)**:

```python
import torch
from torch import nn

class SimpleRnnModel(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.hidden_size = hidden_size
        # Пам'яттєва комірка: лінійний шар + tanh для стабільності
        self.memory_cell = nn.Sequential(
            nn.Linear(input_size + hidden_size, hidden_size),
            nn.Tanh()
        )
        self.output = nn.Linear(hidden_size, output_size)

    def forward(self, X):
        batch_size, window_length, dimensionality = X.shape
        X_time_first = X.transpose(0, 1) # [час, батч, ознаки]
        H = torch.zeros(batch_size, self.hidden_size, device=X.device)
        
        for X_t in X_time_first:
            # Об'єднуємо вхід та попередній стан
            XH = torch.cat((X_t, H), dim=1) 
            H = self.memory_cell(XH)
            
        return self.output(H)
```
