### Merge:
```python
df1 = pd.DataFrame({'employee': ['Bob', 'Jake', 'Lisa', 'Sue'],
                    'group': ['Accounting', 'Engineering', 'Engineering', 'HR']})

df2 = pd.DataFrame({'employee': ['Lisa', 'Bob', 'Jake', 'Sue'],
                    'hire_data': [2004, 2008, 2012, 2014]})

df3 = pd.merge(df1, df2) # шукає спільну колонку, встановлює її як ключ, та мерджить за нею (один-до-одного)

df3
```

```python
df4 = pd.DataFrame({'group': ['Accounting', 'Engineering', 'HR'],
                    'supervisor': ['Carly', 'Guido', 'Steve']})

pd.merge(df3, df4) # у df3 є повторення, у df4 нема - багато-до-одного, group спільний, тому є ключем
```

```python
df5 = pd.DataFrame({'group': ['Accounting', 'Accounting', 'Engineering', 'Engineering'],
                    'skills': ['math', 'spreadsheets', 'coding', 'linux']})

print(df1, '\n')
print(df5, '\n')

# спочатку обирається спільна колонка, яка стане ключем - group
# потім обирається кожний employee, дублюється стільки разів, скільки повторів, і додається колонка skills,
# значення якої прив'язані до наших ключей

print(pd.merge(df1, df5)) # багато-до-багатьох
```

```python
df1a = df1.set_index('employee')

```

`df.join()` у **pandas** — це метод для об’єднання DataFrame-ів по **індексу** (на відміну від `merge`, який зазвичай працює по колонках).

```python
df1a.join(df2a) # equals to pd.merge(df1a, df2a, left_index=True, right_index=True)
```

