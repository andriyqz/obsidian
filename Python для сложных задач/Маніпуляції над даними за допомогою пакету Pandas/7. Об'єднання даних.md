### Concat:

```python
def make_df(cols, ind):
    data = {c: [str(c) + str(i) for i in ind]
            for c in cols}
    return pd.DataFrame(data, ind)

make_df('ABC', range(3))
```

```python
try:
    pd.concat([x, y], verify_integrity=True)
except ValueError as e:
    print(e)
```

```python
pd.concat([x, y], ignore_index=True) # повністю реіндексує датафрейм
```

```python
pd.concat([x, y], keys=['x', 'y']) # ключі МультиІндексу, які встановляться, щоб дубліковані індекси можна було розрізняти
```

```python
df5 = make_df('ABC', [1, 2])
df6 = make_df('BCD', [3, 4])

print(pd.concat([df5, df6], join='outer')) # всі індекси, пропуски заповнюються NA-значеннями
print('\n')

print(pd.concat([df5, df6], join='inner')) # переріз колонок
print('\n')

print(pd.concat([df5, df6]).reindex(df5.columns, axis=1)) # тільки колонки df5, пропуски заповнюються NA-значеннями
```

### Merge:
```python
df1 = pd.DataFrame({'employee': ['Bob', 'Jake', 'Lisa', 'Sue'],
                    'group': ['Accounting', 'Engineering', 'Engineering', 'HR']})

df2 = pd.DataFrame({'employee': ['Lisa', 'Bob', 'Jake', 'Sue'],
                    'hire_data': [2004, 2008, 2012, 2014]})

df3 = pd.merge(df1, df2) # шукає спільну колонку, встановлює її як ключ, та мерджить за нею (один-до-одного)

df3
```
