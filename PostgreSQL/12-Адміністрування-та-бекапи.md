# Адміністрування та бекапи

## Користувачі та права

```sql
-- Створення
CREATE USER app_user WITH PASSWORD 'secure_pass';
ALTER USER app_user WITH SUPERUSER;  -- або NOSUPERUSER

-- База даних
CREATE DATABASE mydb OWNER app_user;
GRANT ALL PRIVILEGES ON DATABASE mydb TO app_user;

-- Права на таблиці (схема)
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES
IN SCHEMA public TO app_user;
GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO app_user;

-- Ролі
CREATE ROLE readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO readonly;
GRANT readonly TO app_user;
```

## pg_dump — бекап

```bash
# Одна БД
pg_dump -U postgres -d mydb > backup.sql

# Стислий бекап
pg_dump -U postgres -d mydb -F c > backup.dump

# Тільки схема (без даних)
pg_dump -U postgres -d mydb --schema-only > schema.sql

# Тільки дані
pg_dump -U postgres -d mydb --data-only > data.sql
```

## pg_restore — відновлення

```bash
# З SQL
psql -U postgres -d mydb < backup.sql

# З custom формату
pg_restore -U postgres -d mydb backup.dump
```

## pg_dumpall — вся система

```bash
pg_dumpall -U postgres > full_backup.sql
```

## Моніторинг

```sql
-- Активні з'єднання
SELECT pid, usename, state, query, wait_event
FROM pg_stat_activity;

-- Розмір бази даних
SELECT pg_size_pretty(pg_database_size('mydb'));

-- Розмір таблиці
SELECT pg_size_pretty(pg_total_relation_size('users'));

-- Невикористані індекси
SELECT schemaname, tablename, indexname, idx_scan
FROM pg_stat_user_indexes
WHERE idx_scan = 0;
```

## Налаштування (postgresql.conf)

```
shared_buffers = 25% від RAM
effective_cache_size = 50-75% від RAM
work_mem = 4-32MB (на сортування/хеші)
maintenance_work_mem = 64-256MB (VACUUM, CREATE INDEX)
max_connections = 20-200 залежно від RAM
```
