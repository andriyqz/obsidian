# Вступ до PostgreSQL

**PostgreSQL** — об'єктно-реляційна СКБД з відкритим кодом.

## Основні характеристики

- **ACID** — атомарність, узгодженість, ізоляція, довговічність
- **MVCC** (Multi-Version Concurrency Control) — конкурентний доступ без блокувань на читання
- **Розширюваність** — власні типи даних, індекси, функції
- **JSON/JSONB** — гнучка робота з напівструктурованими даними
- **Повнотекстовий пошук**
- **Транзакції** з рівнями ізоляції (READ COMMITTED, REPEATABLE READ, SERIALIZABLE)

## Типові команди psql

```sql
-- Підключення
psql -U username -d dbname

-- Основні мета-команди
\l        -- список БД
\c dbname -- переключити БД
\dt       -- список таблиць
\d tablename -- опис таблиці
\di       -- список індексів
\du       -- список користувачів
\q        -- вихід
```

## Архітектура

- **postmaster** — головний процес (демон)
- **shared buffers** — спільний кеш сторінок
- **WAL** (Write-Ahead Log) — журнал попереднього запису
