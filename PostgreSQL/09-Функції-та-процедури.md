# Функції та процедури

## Мови для написання:

- **SQL** — вбудована, для простих запитів
- **PL/pgSQL** — процедурна мова (змінні, цикли, умови)
- **PL/Python**, **PL/Perl**, **PL/Tcl** — зовнішні мови

## Функції (повертають значення)

```sql
-- SQL-функція
CREATE FUNCTION get_user_email(user_id INTEGER)
RETURNS TEXT AS $$
    SELECT email FROM users WHERE id = user_id;
$$ LANGUAGE SQL;
```

```sql
-- PL/pgSQL функція
CREATE FUNCTION get_user_count_by_city(city_name TEXT)
RETURNS INTEGER AS $$
DECLARE
    count INTEGER;
BEGIN
    SELECT COUNT(*) INTO count FROM users WHERE city = city_name;
    RETURN count;
END;
$$ LANGUAGE plpgsql;
```

## Процедури (не повертають значення, з'явились у PG11)

```sql
CREATE PROCEDURE transfer_funds(
    from_id INTEGER, to_id INTEGER, amount NUMERIC
)
LANGUAGE plpgsql AS $$
BEGIN
    UPDATE accounts SET balance = balance - amount WHERE id = from_id;
    UPDATE accounts SET balance = balance + amount WHERE id = to_id;
    COMMIT;
END;
$$;

CALL transfer_funds(1, 2, 500);
```

## Функції, що повертають таблиці

```sql
CREATE FUNCTION get_users_by_city(city_name TEXT)
RETURNS TABLE(id INTEGER, name TEXT, email TEXT) AS $$
BEGIN
    RETURN QUERY SELECT u.id, u.name, u.email FROM users u WHERE u.city = city_name;
END;
$$ LANGUAGE plpgsql;
```

## Тригери (функції, що викликаються автоматично)

```sql
CREATE FUNCTION log_update()
RETURNS TRIGGER AS $$
BEGIN
    INSERT INTO audit_log(table_name, old_data, new_data)
    VALUES (TG_TABLE_NAME, row_to_json(OLD), row_to_json(NEW));
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_users_update
AFTER UPDATE ON users
FOR EACH ROW EXECUTE FUNCTION log_update();
```
