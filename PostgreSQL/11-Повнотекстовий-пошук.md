# Повнотекстовий пошук

## Як це працює

1. **Текст → tsvector** — лематизація (стемінг), видалення стоп-слів
2. **Запит → tsquery** — пошуковий запит з логічними операторами
3. **Відповідність** — `@@` оператор

## Створення tsvector

```sql
SELECT to_tsvector('ukrainian', 'Привіт, як справи?');
-- 'справ':2 'привіт':1

SELECT to_tsvector('english', 'The cats are running');
-- 'cat':2 'run':3
```

## tsquery

```sql
SELECT to_tsquery('ukrainian', 'кіт & миша');
-- 'кіт' & 'миш'

SELECT to_tsquery('english', 'cat & mouse');
SELECT to_tsquery('english', 'cat | dog');
SELECT to_tsquery('english', '!cat');
SELECT phraseto_tsquery('english', 'cat mouse');
```

## Пошук

```sql
SELECT * FROM articles
WHERE to_tsvector('ukrainian', title || ' ' || content)
      @@ to_tsquery('ukrainian', 'кіт & миша');
```

## Додаткові функції

```sql
SELECT ts_rank(to_tsvector('Якийсь текст'), to_tsquery('текст')) AS relevance;

SELECT ts_headline('Дуже довгий текст про пошук', to_tsquery('пошук'),
                   'StartSel=<mark>, StopSel=</mark>');
```

## Індекси для повнотекстового пошуку

```sql
-- GIN (швидше) для пошуку
CREATE INDEX idx_articles_search ON articles
USING GIN (to_tsvector('ukrainian', title || ' ' || content));

-- GiST (повільніше, але менше оновлення)
-- GIN рекомендується для більшості випадків
```

## Стовпець з tsvector (автоматичне оновлення)

```sql
ALTER TABLE articles ADD COLUMN search_vector TSVECTOR;

CREATE FUNCTION update_search_vector()
RETURNS TRIGGER AS $$
BEGIN
    NEW.search_vector := to_tsvector('ukrainian', NEW.title || ' ' || NEW.content);
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_articles_search
BEFORE INSERT OR UPDATE ON articles
FOR EACH ROW EXECUTE FUNCTION update_search_vector();

CREATE INDEX idx_articles_search ON articles USING GIN (search_vector);
```
