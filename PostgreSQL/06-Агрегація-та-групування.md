# Агрегація та групування

## Агрегатні функції:

| Функція        | Опис              |
| -------------- | ----------------- |
| `COUNT()`      | кількість рядків  |
| `SUM()`        | сума              |
| `AVG()`        | середнє           |
| `MIN()`        | мінімум           |
| `MAX()`        | максимум          |
| `STRING_AGG()` | об'єднати рядки   |
| `ARRAY_AGG()`  | об'єднати в масив |

```sql
SELECT COUNT(*) FROM users;
SELECT AVG(age) FROM users;
SELECT MIN(price), MAX(price) FROM products;
```

## GROUP BY

```sql
SELECT city, COUNT(*) AS user_count
FROM users
GROUP BY city;

SELECT user_id, SUM(total) AS total_spent, COUNT(*) AS order_count
FROM orders
GROUP BY user_id;
```

## HAVING — фільтрація груп (після GROUP BY)

```sql
SELECT city, COUNT(*) AS count
FROM users
GROUP BY city
HAVING COUNT(*) > 5;

SELECT user_id, SUM(total) AS total
FROM orders
GROUP BY user_id
HAVING SUM(total) > 1000;
```

## GROUPING SETS / ROLLUP / CUBE

```sql
SELECT city, status, COUNT(*)
FROM orders
GROUP BY GROUPING SETS ((city), (status), ()); -- () = загальний підсумок

SELECT city, status, COUNT(*)
FROM orders
GROUP BY ROLLUP (city, status);  -- ієрархічні підсумки

SELECT city, status, COUNT(*)
FROM orders
GROUP BY CUBE (city, status);    -- всі комбінації
```
