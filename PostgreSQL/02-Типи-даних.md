# Типи даних у PostgreSQL

## Числові типи

| Тип         | Розмір   | Опис                     |
| ----------- | -------- | ------------------------ |
| `SMALLINT`  | 2 байти  | -32,768 .. 32,767        |
| `INTEGER`   | 4 байти  | -2^31 .. 2^31-1          |
| `BIGINT`    | 8 байтів | -2^63 .. 2^63-1          |
| `DECIMAL`   | змінний  | точні дробові числа      |
| `NUMERIC`   | змінний  | те саме, що DECIMAL      |
| `REAL`      | 4 байти  | плаваюча точка, ~6 цифр  |
| `DOUBLE`    | 8 байтів | плаваюча точка, ~15 цифр |
| `SERIAL`    | 4 байти  | автоінкремент (INTEGER)  |
| `BIGSERIAL` | 8 байтів | автоінкремент (BIGINT)   |

## Рядкові типи

- `CHAR(n)` — фіксована довжина
- `VARCHAR(n)` — змінна довжина з лімітом
- `TEXT` — необмежена довжина

## Типи дати/часу

- `DATE` — дата (рік-місяць-день)
- `TIME` — час (години:хвилини:секунди)
- `TIMESTAMP` — дата + час
- `TIMESTAMPTZ` — з часовим поясом
- `INTERVAL` — інтервал часу

## Спеціальні типи

- `BOOLEAN` — TRUE / FALSE / NULL
- `UUID` — універсальний ідентифікатор
- `JSON` / `JSONB` — JSON (BIN — бінарний, з індексацією)
- `ARRAY` — масиви (`INTEGER[]`, `TEXT[]`)
- `ENUM` — перелічуваний тип
- `TSVECTOR` / `TSQUERY` — для повнотекстового пошуку
